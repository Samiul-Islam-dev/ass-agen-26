# News Portal (MERN)
Full-stack news portal. React + Tailwind + Zustand | Express + Node + MongoDB.

## Run
Server: `cd server && npm install && npm run dev`  (http://localhost:5000)
Client: `cd client && npm install && npm run dev`  (http://localhost:5173)
Copy `server/.env.example` to `server/.env` before running.
